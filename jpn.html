The JPN, or Javascript Proxy Network, is my one and only completed Javascript project.
I created the JPN because I was bored one day and wanted to see if I could write my own mini browser,
short answer, I did. I choose to not publicly release this project because people will go
crazy because of the amount of freedom you can have with it. It has full redirect support, sound support,
AND it even rewrites iframes inside the iframe that the page is displayed in. It essentially hosts pages
from a seperate domain so the route is proxied. I wrote 700 lines of code to complete it, without AI.
I did NOT just make a UI and bolt rammerhead onto it, i actually built my own front and backend from complete scratch.
